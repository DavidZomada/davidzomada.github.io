# Material Symbols Rounded (subset)

Self-hosted so readers' IPs are not sent to Google Fonts.

- Source: Google Fonts, `Material Symbols Rounded`, axes `opsz 20..24, wght 500, FILL 1, GRAD 0`, `v386`.
- Subset: only the icons the trip page uses (the `icon_names` list below).
- License: Apache License 2.0 (https://github.com/google/material-design-icons/blob/master/LICENSE).

To add an icon, request the subset again with the new name and replace the `.woff2`:

```
https://fonts.googleapis.com/css2?family=Material+Symbols+Rounded:opsz,wght,FILL,GRAD@20..24,500,1,0&icon_names=<sorted,comma,separated,names>&display=block
```

Current `icon_names`: agriculture, airport_shuttle, arrow_forward, chevron_left, chevron_right, directions_bike, directions_boat, directions_bus, directions_car, electric_scooter, first_page, fit_screen, flight, hiking, last_page, layers, local_shipping, moped, paragliding, sailing, scuba_diving, surfing, tram, train, two_wheeler.
